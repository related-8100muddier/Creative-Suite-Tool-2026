## FAQ

### What video editors does VideoPatch support?

VideoPatch currently supports CapCut, DaVinci Resolve, Filmora, VideoPad, HitFilm, and Movavi.

### Is VideoPatch safe to use?

Yes, VideoPatch is safe and does not contain any tool or components. It only modifies the application to unlock features.

### Do I need an internet connection to use VideoPatch?

No, VideoPatch works offline. However, an internet connection may be required for some editor features that are not related to the patch.

### Will VideoPatch work on the latest versions of the video editors?

We aim to support the latest versions, but sometimes updates may temporarily break compatibility. We will release updates to address this.

### Can I revert the changes made by VideoPatch?

Yes, VideoPatch creates backups of the original files. You can use the 'Restore' option to revert to the original state.

### Does VideoPatch work on Mac or Linux?

No, VideoPatch is designed for Windows only. We do not have plans for other operating systems at this time.

### How do I report a bug or request a feature?

Please open an issue on our GitHub repository, and we will respond as soon as possible.
